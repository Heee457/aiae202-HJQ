# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: everyone taking part in this project — asking a question, filing an issue, reviewing a pull request — is expected to treat other people with respect. Harassment, personal attacks, and discriminatory language are not acceptable.

## Reporting

If you experience or witness behaviour that breaks this code, open an issue in this repository, or contact the maintainers privately if the issue is sensitive. Reports are handled confidentially.
